示例 3 - Cron 触发器
==================

概述:
====
本示例演示如何使用 Cron 触发器进行任务调度。Cron 触发器是 Quartz 中最强大和灵活的触发器类型，
它使用类似 Unix Cron 的表达式来定义复杂的调度规则。

功能特性:
========
- 支持复杂的时间调度表达式
- 可以精确控制任务执行的时间点
- 支持秒、分、时、日、月、周的组合调度
- 可以设置特定时间段内的执行规则
- 支持工作日和周末的不同调度策略

核心概念:
========
1. **Cron 表达式**: 由 6 或 7 个字段组成的时间表达式
   - 秒 (0-59)
   - 分 (0-59) 
   - 时 (0-23)
   - 日 (1-31)
   - 月 (1-12 或 JAN-DEC)
   - 周 (1-7 或 SUN-SAT)
   - 年 (可选, 1970-2099)

2. **特殊字符**:
   - * : 匹配所有值
   - ? : 用于日和周字段，表示不指定值
   - - : 表示范围
   - , : 表示列举
   - / : 表示增量
   - L : 表示最后
   - W : 表示工作日
   - # : 表示第几个

文件说明:
========
- **CronTriggerExample.java**: 主要的示例类，演示了 7 种不同的 Cron 触发器配置
- **SimpleJob.java**: 简单的任务实现类，用于被调度执行
- **cron_triggers_readme.txt**: 本说明文档

运行步骤:
========
1. 确保已正确配置 Quartz 依赖
2. 编译项目: `mvn compile`
3. 运行示例: `mvn exec:java -Dexec.mainClass="org.quartz.examples.example3.CronTriggerExample"`
4. 观察控制台输出，查看不同 Cron 触发器的执行情况

代码执行流程:
============
1. **初始化阶段**:
   - 创建调度器工厂
   - 获取调度器实例
   - 配置日志记录

2. **任务调度阶段**:
   - 创建 7 个不同的任务和触发器
   - 每个触发器使用不同的 Cron 表达式
   - 将任务和触发器注册到调度器

3. **执行阶段**:
   - 启动调度器
   - 等待 5 分钟观察任务执行
   - 关闭调度器并输出统计信息

Cron 表达式示例:
===============
- `0/20 * * * * ?` : 每 20 秒执行一次
- `15 0/2 * * * ?` : 每 2 分钟的第 15 秒执行
- `0 0/2 8-17 * * ?` : 上午 8 点到下午 5 点，每 2 分钟执行
- `0 0/3 17-23 * * ?` : 下午 5 点到晚上 11 点，每 3 分钟执行
- `0 0 10am 1,15 * ?` : 每月 1 号和 15 号上午 10 点执行
- `0,30 * * ? * MON-FRI` : 工作日每分钟的第 0 秒和第 30 秒执行
- `0,30 * * ? * SAT,SUN` : 周末每分钟的第 0 秒和第 30 秒执行

关键代码说明:
============
1. **Cron 触发器创建**:
   ```java
   CronTrigger trigger = newTrigger()
       .withIdentity("trigger1", "group1")
       .withSchedule(cronSchedule("0/20 * * * * ?"))
       .build();
   ```

2. **任务调度**:
   ```java
   Date ft = sched.scheduleJob(job, trigger);
   ```

3. **调度器生命周期管理**:
   ```java
   sched.start();    // 启动调度器
   sched.shutdown(true);  // 关闭调度器
   ```

注意事项:
========
- Cron 表达式的字段顺序很重要，不能颠倒
- 日和周字段不能同时指定，其中一个必须使用 ?
- 表达式区分大小写
- 时间基于服务器本地时区
- 调度器必须启动后任务才会执行

示例7 - 任务中断机制演示
========================

概述：
=====
本示例演示了Quartz调度器如何中断正在运行的任务。这是一个重要的功能，
允许系统在需要时优雅地停止长时间运行的任务。

功能特性：
=========
1. **可中断任务实现**：演示如何实现InterruptableJob接口
2. **中断信号处理**：展示任务如何响应中断请求
3. **优雅退出机制**：演示任务在接收到中断信号后如何安全退出
4. **定期中断测试**：模拟定期中断任务的场景
5. **状态监控**：展示如何监控任务的执行和中断状态

核心概念：
=========
- **InterruptableJob接口**：允许任务被外部中断的特殊接口
- **interrupt()方法**：处理中断请求的回调方法
- **中断标志**：用于在任务执行过程中检查是否收到中断信号
- **优雅退出**：任务在中断时进行必要的清理工作

文件说明：
=========
- **DumbInterruptableJob.java**：可中断任务的实现类
  * 实现InterruptableJob接口
  * 包含中断标志和处理逻辑
  * 演示长时间运行任务的中断处理

- **InterruptExample.java**：中断机制演示的主程序
  * 创建和调度可中断任务
  * 定期发送中断信号
  * 监控任务执行状态

- **interrupting_readme.txt**：本说明文档

运行步骤：
=========
1. 编译项目：mvn compile
2. 运行示例：mvn exec:java -Dexec.mainClass="org.quartz.examples.example7.InterruptExample"
3. 观察控制台输出，查看任务的启动、执行、中断和重启过程
4. 注意任务如何响应中断信号并优雅退出

代码执行流程：
=============
1. **初始化阶段**：
   - 创建调度器实例
   - 配置可中断任务
   - 设置触发器（每5秒执行一次）

2. **任务执行阶段**：
   - 任务开始执行，模拟4秒的工作时间
   - 每秒检查一次中断标志
   - 如果收到中断信号，立即退出

3. **中断测试阶段**：
   - 主程序每7秒发送一次中断信号
   - 观察任务如何响应中断
   - 任务被中断后会重新调度执行

4. **清理阶段**：
   - 关闭调度器
   - 输出执行统计信息

关键代码说明：
=============

**中断标志检查**：
```java
if(_interrupted) {
    _log.info("--- " + _jobKey + "  -- Interrupted... bailing out!");
    return; // 优雅退出
}
```

**中断处理方法**：
```java
public void interrupt() throws UnableToInterruptJobException {
    _log.info("---" + _jobKey + "  -- INTERRUPTING --");
    _interrupted = true; // 设置中断标志
}
```

**定期中断测试**：
```java
for (int i = 0; i < 50; i++) {
    Thread.sleep(7000L);
    sched.interrupt(job.getKey()); // 发送中断信号
}
```

预期行为：
=========
1. 任务每5秒启动一次
2. 每个任务执行需要4秒（模拟工作）
3. 主程序每7秒发送一次中断信号
4. 任务在收到中断信号后会立即退出
5. 调度器会重新调度被中断的任务
6. 可以观察到任务的启动、中断、重启的循环过程

注意事项：
=========
1. **中断响应性**：任务必须定期检查中断标志才能及时响应
2. **资源清理**：在finally块中进行必要的资源清理
3. **异常处理**：中断过程中可能抛出UnableToInterruptJobException
4. **线程安全**：中断标志的访问需要考虑线程安全性
5. **优雅退出**：避免在中断时留下不一致的状态
